# ✏️ CanvasMind

> Draw. Think. Organise.  
> A real-time collaborative whiteboard that understands your ideas.

---

## 🧠 What is this?

CanvasMind is not just a drawing tool.

It’s a **thinking surface** where raw ideas evolve into structured knowledge.

- Sketch freely like a whiteboard  
- Connect ideas visually  
- Organise chaos into meaning  
- (Soon) Let AI assist your thinking  

---

## ⚡ Core Philosophy

> Ideas start messy. Systems make them useful.

Most tools force structure too early.  
CanvasMind lets you:
- **think first**
- **organise later**

---

## 🚀 Features

### ✍️ Freeform Canvas
Draw anything:
- boxes
- arrows
- notes
- connections

No restrictions. No friction.

---

### 🔄 Real-Time Collaboration
Work together instantly using WebSockets:
- multiple users on same board
- live updates
- shared thinking space

---

### 🧩 Smart Organisation *(in progress)*
Turn chaos into clarity:
- auto-align elements  
- group related ideas  
- convert sketches → structured layout  

---

### 🤖 AI Assistance *(experimental)*
Not just chat.

- Understands your canvas  
- Suggests structure  
- Helps refine ideas  

---

## 🏗️ Tech Stack

### Frontend
- React (Vite)
- HTML Canvas / Fabric.js
- Zustand (state)

### Backend
- Node.js (WebSocket server)
- Redis (real-time sync layer)

### AI Layer (planned)
- Gemma / local model
- Graph-based context extraction
